# Spring IoC – Inversion of Control & Dependency Injection

Welcome to my Spring IoC repository!

This repository contains my hands-on practice and practical implementations of Spring Framework's Inversion of Control (IoC) and Dependency Injection (DI) concepts.

It covers XML-based configuration, Java-based configuration, different dependency injection approaches, and Spring Bean Lifecycle.

## 🛠️ Technologies & Tools

- Java
- Spring Framework
- Spring IoC Container
- XML Configuration
- Java-Based Configuration
- Dependency Injection
- Eclipse IDE
